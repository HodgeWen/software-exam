# React 19.1

本文件适用于 **19.1.x**。19.0 的 Actions / `use` / `ref` prop / Context 当 provider / `useOptimistic` 照用。不要用 19.2 才有的 API（`<Activity>`、`useEffectEvent`、`cacheSignal`、`resume` / `resumeAndPrerender`）。

## 19.0 仍该用（细节按需打开 19.0 档）

| 写法 | 不要退回 |
| ---- | -------- |
| `useActionState` + `<form action>` | `useFormState`、手写 pending state |
| 函数组件 `ref` prop | `forwardRef` |
| `<ThemeContext value>` | `<ThemeContext.Provider>` |
| `use(promise)` / `use(Context)`（Promise 须已缓存） | render 里现场 `fetch` |

## Owner Stack（仅 DEV）

`captureOwnerStack()` 只在开发构建里有，用来增强 error overlay / 日志，看「是谁渲染了这个组件」。**业务代码、生产路径不要调用。** 生产 Component Stack 不变。

## `useId`

19.1 的默认前缀是 `«r»`（19.0 是 `:r:`）。不要依赖旧前缀去写 CSS 选择器或测试快照。

## Suspense

19.1 起 Suspense 在 client / server / hydration 都更可用。隐藏内容用条件渲染或 CSS，不要用尚未稳定的 Activity。fallback 冻住时，未完成的边界会在客户端继续渲染——按正常 `Suspense` 写即可，不要为此手搓超时状态机。
