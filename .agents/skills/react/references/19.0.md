# React 19.0

本文件只适用于 **19.0.x**。不要用 19.1 / 19.2 才有的 API（`captureOwnerStack`、`<Activity>`、`useEffectEvent`、`cacheSignal`、`resume` / `resumeAndPrerender`）。

## Actions 与表单

`useActionState` 在 `react`；`useFormStatus` 在 `react-dom`。不要用已弃用的 `useFormState`。

```tsx
import { useActionState } from 'react'
import { useFormStatus } from 'react-dom'

function Submit() {
  const { pending } = useFormStatus()
  return <button type="submit" disabled={pending}>保存</button>
}

function Rename() {
  const [error, submitAction, isPending] = useActionState(
    async (_prev: string | null, formData: FormData) => {
      const err = await updateName(String(formData.get('name')))
      return err
    },
    null,
  )
  return (
    <form action={submitAction}>
      <input name="name" />
      <Submit />
      {error && <p>{error}</p>}
    </form>
  )
}
```

非表单的异步更新用 `startTransition(async () => { ... })`，用返回的 `isPending`。立刻显示最终 UI 用 `useOptimistic`。

表单 Action 成功后，非受控字段会自动 reset。要手动 reset 用 `react-dom` 的 `requestFormReset`。

## `use`

```tsx
import { use, Suspense } from 'react'

function Comments({ commentsPromise }: { commentsPromise: Promise<Comment[]> }) {
  const comments = use(commentsPromise)
  return comments.map((c) => <p key={c.id}>{c.body}</p>)
}

function Heading({ children }: { children?: React.ReactNode }) {
  if (children == null) return null
  const theme = use(ThemeContext) // 可以放在 early return 之后；useContext 不行
  return <h1 style={{ color: theme.color }}>{children}</h1>
}
```

Client 组件里不要 `use(fetch(url))` / `use(new Promise(...))`。Promise 从服务端、框架 loader 或 `cache()` 传入。

## ref、Context、清理

```tsx
function Field({ ref, ...props }: React.ComponentProps<'input'>) {
  return <input ref={ref} {...props} />
}

<ThemeContext value="dark">{children}</ThemeContext>

<input
  ref={(node) => {
    node?.focus()
    return () => {
      /* 卸载时清理；有返回值时 React 不再用 null 调一次 */
    }
  }}
/>
```

`ref={el => (n = el)}` 这种隐式返回会被 TS 当成 cleanup。写成 `{ n = el }`。

## 其它 19.0 API

- `useDeferredValue(value, initialValue)`：首屏先用 `initialValue`，再在后台切到 `value`。
- 静态 HTML：`react-dom/static` 的 `prerender` / `prerenderToNodeStream`。流式 SSR 仍用 `react-dom/server`。Node 里优先 Node Stream API，不要无故改 Web Stream。
- 组件内可渲染 `<title>` / `<meta>` / `<link rel="stylesheet">` / `<script>`；样式与脚本按优先级提升。
- 资源：`react-dom` 的 `prefetchDNS` / `preconnect` / `preload` / `preinit`。项目已有框架资源 API 则跟框架走。
